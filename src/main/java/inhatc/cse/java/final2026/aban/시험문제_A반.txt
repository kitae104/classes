##################################################################
# 1세트. 과일 가게
##################################################################
각 과일(Fruit)은 이름(name), 분류(category), 가격(price), 재고(stock) 정보를 가집니다.

[데이터]
("딸기",     "베리류",  8000, 12)
("블루베리", "베리류", 15000,  6)
("오렌지",   "감귤류",  5000, 20)
("한라봉",   "감귤류", 12000,  8)
("망고",     "열대",    9000, 15)
("바나나",   "열대",    4000, 30)
("파인애플", "열대",    7000,  5)

------------------------------------------------------------------
 1번. 비싼 과일 이름 목록 만들기  
------------------------------------------------------------------
 1. 가격이 8,000원 이상인 과일만 골라낸다.
 2. 그 과일의 "이름"만 뽑아낸다.
 3. 이름을 가나다순으로 정렬하여 한 줄에 하나씩 출력한다.

[예상 출력 결과]
== 1번  8,000원 이상 과일 (이름 가나다순) ==
과일1
과일2
...

------------------------------------------------------------------
 2번. 특정 분류를 비싼 순서로 진열하기  
------------------------------------------------------------------
 1. 분류가 "열대"인 과일만 골라낸다.
 2. 가격이 비싼 순서(내림차순)로 정렬한다.
 3. "이름 - 가격원" 형태로 바꿔 한 줄에 하나씩 출력한다.

[예상 출력 결과]
== 2번 열대 과일 (가격 내림차순) ==
과일1 - 000원
과일2 - 000원
...

------------------------------------------------------------------
 3번. 가격 기준으로 두 진열대로 나누기  
------------------------------------------------------------------
 1. 전체 과일을 가격 8,000원 기준으로 "이상" 그룹과 "미만" 그룹
    두 묶음으로 한 번에 나눈다. (참/거짓 분할)
 2. [8,000원 이상] 그룹의 이름을, 이어서 [8,000원 미만] 그룹의 이름을 출력한다.
 3. 각 이름 앞에는 공백 2칸을 붙인다. 그룹 내 순서는 원본 순서를 따른다.

[예상 출력 결과]
== 3번 가격 8,000원 기준 분할 ==
[8,000원 이상]
  과일1
  과일2
  ...
[8,000원 미만]
  과일1
  과일2
  ...

------------------------------------------------------------------
 4번. 분류별 과일 종류 수 집계 후 정렬  
------------------------------------------------------------------
 1. 같은 분류끼리 묶어 분류별 "과일 종류 수"를 센다.
 2. 1차: 종류 수 내림차순, 2차(동률): 분류명 가나다순으로 정렬한다.
 3. "분류 : N종" 형태로 한 줄씩 출력한다.

[예상 출력 결과]
== 4번 분류별 과일 종류 수 (개수 내림차순, 동률은 분류명 오름차순) ==
분류1 : N종
분류2 : N종
...

##################################################################
# 2세트. 학생 동아리
##################################################################

------------------------------------------------------------------
 공통 데이터 - 학생(Student) 리스트
------------------------------------------------------------------
각 학생(Student)은 이름(name), 동아리(club), 점수(score), 봉사시간(volunteer) 정보를 가집니다.

[데이터]
("김하늘", "코딩", 92, 10)
("이준호", "코딩", 85,  4)
("박서영", "밴드", 78,  8)
("최민재", "밴드", 88,  6)
("정유진", "미술", 95, 12)
("강도현", "미술", 70,  5)
("윤지아", "코딩", 90,  7)

------------------------------------------------------------------
 1번. 조건을 만족하는 학생 수 세기  
------------------------------------------------------------------
 1. 점수(score)가 85점 이상인 학생만 골라낸다.
 2. 골라낸 학생이 몇 명인지 센 뒤 "N명" 형태로 출력한다.

[예상 출력 결과]
== 점수 85점 이상 학생 수 ==
N명

------------------------------------------------------------------
 2번. 점수 상위 3명 뽑기  
------------------------------------------------------------------
 1. 전체 학생을 점수가 높은 순서(내림차순)로 정렬한다.
 2. 그 중 상위 3명만 남긴다.
 3. "이름(점수점)" 형태로 바꿔 한 줄에 하나씩 출력한다.

[예상 출력 결과]
== 점수 상위 3명 ==
학생1(000점)
학생2(000점)
학생3(000점)

------------------------------------------------------------------
 3번. 전체 학생 점수의 요약 통계  
------------------------------------------------------------------
 1. 전체 학생의 점수에 대한 통계(인원/합계/최고/최저/평균)를 한 번에 구한다.
    (요약 통계 기능 활용. 평균은 소수점 첫째 자리까지)
 2. 아래 형식으로 출력한다.

[예상 출력 결과]
== 전체 학생 점수 통계 ==
인원 : N명
합계 : 000점
최고 : 000점
최저 : 000점
평균 : 000.0점

------------------------------------------------------------------
 4번. 종합 - 봉사 활동 학생의 점수 순위표  
------------------------------------------------------------------
 1. 봉사시간(volunteer)이 6시간 이상인 학생만 골라낸다.
 2. 점수가 높은 순서(내림차순)로 정렬한 뒤 상위 3명만 남긴다.
 3. "이름(점수점)" 형태로 바꿔 한 줄에 하나씩 출력한다.
 4. 마지막 줄에 1위(점수가 가장 높은) 학생의 이름을 "1위: 이름" 형태로 출력한다.

[예상 출력 결과]
== 봉사시간 6시간 이상, 점수 상위 3명 ==
학생1(000점)
학생2(000점)
학생3(000점)
1위: 학생1
