------------------------------------------------------------------
 공통 데이터 - 도서(Book) 리스트
------------------------------------------------------------------
각 도서는 제목(title), 저자(author), 카테고리(category),
가격(price), 재고(stock) 정보를 가집니다.

static class Book {
    String title;
    String author;
    String category;
    int price;   // 정가(원)
    int stock;   // 재고(권)

    public Book(String title, String author, String category, int price, int stock) {
        this.title = title;
        this.author = author;
        this.category = category;
        this.price = price;
        this.stock = stock;
    }
    public String getTitle()    { return title; }
    public String getAuthor()   { return author; }
    public String getCategory() { return category; }
    public int    getPrice()    { return price; }
    public int    getStock()    { return stock; }
}

List<Book> books = Arrays.asList(
    new Book("자바의정석",   "남궁성",     "프로그래밍", 30000, 15),
    new Book("이펙티브자바", "조슈아",     "프로그래밍", 36000,  8),
    new Book("클린코드",     "로버트",     "프로그래밍", 33000,  5),
    new Book("데미안",       "헤세",       "소설",      12000, 20),
    new Book("어린왕자",     "생텍쥐페리", "소설",       9000, 25),
    new Book("코스모스",     "세이건",     "과학",      18000, 12),
    new Book("이기적유전자", "도킨스",     "과학",      20000,  7),
    new Book("총균쇠",       "다이아몬드", "역사",      22000, 10)
);

 1번. 가격이 비싼 도서의 제목 목록 만들기   (난이도: 하, 15점)
==================================================================
서점에서 "가격이 20,000원 이상"인 도서들의 제목만 모아
가나다순으로 정리한 목록을 출력하려고 합니다.

[처리해야 할 일]
 1. 전체 도서 중에서 가격이 20,000원 이상인 도서만 골라낸다.
 2. 골라낸 도서에서 "제목"이라는 값 하나만 뽑아낸다.
 3. 뽑아낸 제목들을 가나다순(오름차순)으로 나열한다.
 4. 한 줄에 제목 하나씩 출력한다.

[예상 출력 결과]
== 20,000원 이상 도서 (제목 가나다순) ==
이기적유전자
이펙티브자바
자바의정석
총균쇠
클린코드


==================================================================
 2번. 특정 카테고리 도서를 비싼 순서로 진열하기   (난이도: 중하, 18점)
==================================================================
"프로그래밍" 카테고리에 속한 도서들을 가격이 비싼 순서대로
진열대에 올리려고 합니다. 진열 라벨은 "제목 - 가격원" 형태입니다.

[처리해야 할 일]
 1. 카테고리가 "프로그래밍"인 도서만 골라낸다.
 2. 가격이 비싼 순서(내림차순)가 되도록 순서를 정렬한다.
 3. 각 도서를 "제목 - 가격원" 형태의 문자열로 바꾼다.
    (예: 이펙티브자바 - 36000원)
 4. 한 줄에 하나씩 출력한다.

[예상 출력 결과]
== 프로그래밍 도서 (가격 내림차순) ==
이펙티브자바 - 36000원
클린코드 - 33000원
자바의정석 - 30000원


==================================================================
 3번. 가격 기준으로 두 진열대로 나누기   (난이도: 중, 20점)
==================================================================
도서를 가격 20,000원을 기준선으로 삼아,
"이상" 진열대와 "미만" 진열대 두 곳으로 나누려고 합니다.

[처리해야 할 일]
 1. 전체 도서를 "가격 20,000원 이상"인 그룹과
    "20,000원 미만"인 그룹, 딱 두 묶음으로 한 번에 나눈다.
 2. 먼저 [20,000원 이상] 그룹에 속한 도서들의 제목을 출력한다.
 3. 이어서 [20,000원 미만] 그룹에 속한 도서들의 제목을 출력한다.
 4. 각 제목 앞에는 공백 2칸을 붙여서 출력한다.

[안내]
 - 조건(참/거짓)에 따라 두 묶음으로 나누는 작업을 떠올려 보세요.
 - 각 그룹 안에서의 순서는 원본 데이터에 적힌 순서를 그대로 따릅니다.
   (별도로 정렬하지 않습니다.)

[예상 출력 결과]
[20,000원 이상]
  자바의정석
  이펙티브자바
  클린코드
  이기적유전자
  총균쇠
[20,000원 미만]
  데미안
  어린왕자
  코스모스


==================================================================
 4번. 카테고리별 보유 권수 집계 후 정렬   (난이도: 중상, 22점)
==================================================================
카테고리별로 보유 도서가 몇 권인지 세어,
많은 순서대로 보고서를 만들려고 합니다.

[처리해야 할 일]
 1. 같은 카테고리끼리 묶어, 카테고리별 도서 "권수"를 센다.
 2. 집계 결과를 아래 두 기준으로 정렬한다.
      - 1차 기준: 권수가 많은 순서(내림차순)
      - 2차 기준: 권수가 같으면 카테고리명 가나다순(오름차순)
 3. "카테고리 : N권" 형태로 한 줄씩 출력한다.

[안내]
 - 카테고리별로 묶어 집계한 결과는 순서가 보장되지 않습니다.
   따라서 출력 전에 위 기준대로 "다시 정렬"하는 과정이 필요합니다.
 - 과학과 소설은 각각 2권으로 권수가 같으므로,
   카테고리명 가나다순에 따라 과학 -> 소설 순으로 출력됩니다.

[예상 출력 결과]
== 카테고리별 도서 권수 (권수 내림차순, 동률은 카테고리명 오름차순) ==
프로그래밍 : 3권
과학 : 2권
소설 : 2권
역사 : 1권


==================================================================
 5번. 종합 - 재고 충분 도서의 카테고리별 정가 합계   (난이도: 상, 25점)
==================================================================
재고가 넉넉한 도서들만 대상으로, 카테고리별 정가 합계를 구해
매출 잠재력 보고서를 한 줄로 만들려고 합니다.

[처리해야 할 일]
 1. 재고(stock)가 10권 이상인 도서만 골라낸다.
 2. 골라낸 도서를 카테고리별로 묶어, 카테고리별 "정가(price)의 합계"를 구한다.
 3. 합계가 큰 순서(내림차순)로 정렬한다.
 4. 각 항목을 "카테고리(합계원)" 형태로 바꾸고,
    전체를 " > " 로 이어 한 줄로 출력한다.
    (예: 프로그래밍(30000원) > 역사(22000원) > ...)
 5. 마지막 줄에 정가 합계가 가장 큰 카테고리의 이름을 출력한다.

[안내]
 - 재고 10권 이상 도서는
   자바의정석(15), 데미안(20), 어린왕자(25), 코스모스(12), 총균쇠(10) 입니다.
 - 소설 카테고리는 데미안(12000) + 어린왕자(9000) = 21000원 처럼 합산됩니다.
 - 카테고리별로 묶어 합계를 구한 결과는 순서가 보장되지 않으므로,
   출력 전에 합계 기준으로 다시 정렬해야 합니다.

[예상 출력 결과]
== 재고 10권 이상, 카테고리별 정가 합계 (내림차순) ==
프로그래밍(30000원) > 역사(22000원) > 소설(21000원) > 과학(18000원)
정가 합계 1위 카테고리: 프로그래밍
