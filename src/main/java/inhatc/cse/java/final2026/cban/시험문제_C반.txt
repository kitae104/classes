##################################################################
# 1세트. 산
##################################################################

각 산(Mountain)은 산이름(name), 지역(region), 높이(height), 방문객(visitors) 정보를 가집니다.
높이의 단위는 "m", 방문객의 단위는 "만 명" 입니다.

[데이터]
("설악산", "강원", 1708, 350)
("태백산", "강원", 1567, 120)
("지리산", "경상", 1915, 280)
("가야산", "경상", 1430,  90)
("한라산", "전라", 1947, 400)
("무등산", "전라", 1187, 250)
("오대산", "강원", 1563, 100)

------------------------------------------------------------------
 1번. 전체 방문객 합계 구하기 
------------------------------------------------------------------
 1. 전체 산의 방문객(visitors)을 모두 더한다.
 2. 합계를 "N만 명" 형태로 출력한다.

[예상 출력 결과]
== 전체 산 방문객 합계 ==
00만 명

------------------------------------------------------------------
 2번. 높은 산 이름 한 줄로 연결하기  
------------------------------------------------------------------
 1. 높이가 1,600m 이상인 산만 골라낸다.
 2. 그 산의 "이름"만 뽑아낸다.
 3. 이름들을 ", " (쉼표+공백)로 이어 한 줄로 출력한다. (원본 순서 유지)

[예상 출력 결과]
== 1,600m 이상 산 목록 ==
산이름1, 산이름2, 산이름3

------------------------------------------------------------------
 3번. 지역 종류를 중복 없이 뽑기 
------------------------------------------------------------------
 1. 모든 산에서 "지역(region)"만 뽑아낸다.
 2. 같은 지역이 여러 번 나오므로 중복을 제거한다. 
 3. 지역명을 가나다순으로 정렬하여 한 줄에 하나씩 출력한다.

[예상 출력 결과]
== 산이 위치한 지역 종류 (가나다순) ==
지역1
지역2
지역3

------------------------------------------------------------------
 4번. reduce 로 높이 집계하기  
------------------------------------------------------------------
 1. reduce 를 사용하여 전체 산의 높이 합계를 구한다.
 2. reduce 를 사용하여 가장 높은 산의 높이를 구한다.
 3. 아래 형식으로 출력한다.

[예상 출력 결과]
== 높이 reduce 집계 ==
높이 합계(reduce): 11317m
최고 높이(reduce): 1947m

##################################################################
# 2세트. 자동차
##################################################################

각 차(Car)는 차종(name), 제조사(maker), 가격(price), 연비(efficiency) 정보를 가집니다.
가격의 단위는 "만원", 연비의 단위는 "km/L" 입니다.

[데이터]
("아반떼",     "현대", 2000, 15)
("쏘나타",     "현대", 3000, 13)
("팰리세이드", "현대", 4800,  9)
("셀토스",     "기아", 2500, 14)
("쏘렌토",     "기아", 3800, 12)
("카니발",     "기아", 4200, 10)
("캡처",       "르노", 2800, 13)
("아르카나",   "르노", 3200, 11)

------------------------------------------------------------------
 1번. 조건을 만족하는 차 수 세기 
------------------------------------------------------------------
 1. 연비(efficiency)가 13km/L 이상인 차만 골라낸다.
 2. 골라낸 차가 몇 대인지 센 뒤 "N대" 형태로 출력한다.

[예상 출력 결과]
== 연비 13km/L 이상 차 수 ==
N대

------------------------------------------------------------------
 2번. 가격 상위 3개 차종 뽑기 
------------------------------------------------------------------
 1. 전체 차를 가격이 비싼 순서(내림차순)로 정렬한다.
 2. 그 중 상위 3개만 남긴다.
 3. "차종(가격만원)" 형태로 바꿔 한 줄에 하나씩 출력한다.

[예상 출력 결과]
== 가격 상위 3개 차종 ==
차종1(00원만원)
차종2(00원만원)
차종3(00원만원)

------------------------------------------------------------------
 3번. 차종별 연비표 만들기  
------------------------------------------------------------------
 1. 각 차의 "차종(name)"을 키로, "연비(efficiency)"를 값으로 하는
    Map 으로 변환한다. 
 2. 차종 가나다순으로 정렬한다.
 3. "차종 : N km/L" 형태로 한 줄씩 출력한다.

[예상 출력 결과]
== 차종별 연비표 (차종 가나다순) ==
차종1 : 00km/L
차종2 : 00km/L
차종3 : 00km/L
...

------------------------------------------------------------------
 4번. 종합 - 연비 좋은 차의 가격 순위표  
------------------------------------------------------------------
 1. 연비(efficiency)가 12km/L 이상인 차만 골라낸다.
 2. 가격이 비싼 순서(내림차순)로 정렬한 뒤 상위 3개만 남긴다.
 3. "차종(가격만원)" 형태로 바꿔 한 줄에 하나씩 출력한다.
 4. 마지막 줄에 1위(가격이 가장 비싼) 차종의 이름을 "1위: 차종" 형태로 출력한다.

[예상 출력 결과]
== 연비 12km/L 이상, 가격 상위 3개 ==
차종1(00만원)
차종2(00만원)
차종3(00만원)
1위: 차종1
