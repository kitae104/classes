------------------------------------------------------------------
 공통 데이터 - 영화(Movie) 리스트
------------------------------------------------------------------
각 영화는 제목(title), 장르(genre), 개봉연도(year),
평점(score), 관객수(audience) 정보를 가집니다.
평점은 100점 만점, 관객수의 단위는 "만 명" 입니다.

static class Movie {
    String title;
    String genre;
    int year;       // 개봉연도
    int score;      // 평점 (100점 만점)
    int audience;   // 누적 관객수 (만 명)

    public Movie(String title, String genre, int year, int score, int audience) {
        this.title = title;
        this.genre = genre;
        this.year = year;
        this.score = score;
        this.audience = audience;
    }
    public String getTitle()    { return title; }
    public String getGenre()    { return genre; }
    public int    getYear()     { return year; }
    public int    getScore()    { return score; }
    public int    getAudience() { return audience; }
}

List<Movie> movies = Arrays.asList(
    new Movie("기생충",       "드라마", 2019, 95, 1008),
    new Movie("괴물",         "액션",   2006, 88, 1301),
    new Movie("올드보이",     "스릴러", 2003, 92,  326),
    new Movie("부산행",       "액션",   2016, 85, 1156),
    new Movie("암살",         "액션",   2015, 83, 1270),
    new Movie("택시운전사",   "드라마", 2017, 89, 1218),
    new Movie("곡성",         "스릴러", 2016, 87,  687),
    new Movie("82년생김지영", "드라마", 2019, 80,  367)
);


==================================================================
 1번. 평점 높은 명작 영화 제목 목록 만들기   (난이도: 하, 15점)
==================================================================
"평점이 90점 이상"인 명작 영화들의 제목만 모아,
가나다순으로 정리한 목록을 출력하려고 합니다.

[처리해야 할 일]
 1. 전체 영화 중에서 평점(score)이 90점 이상인 영화만 골라낸다.
 2. 골라낸 영화에서 "제목"이라는 값 하나만 뽑아낸다.
 3. 뽑아낸 제목을 가나다순(오름차순)으로 나열한다.
 4. 한 줄에 제목 하나씩 출력한다.

[예상 출력 결과]
== 평점 90점 이상 영화 (제목 가나다순) ==
기생충
올드보이


==================================================================
 2번. 특정 장르 영화를 흥행 순서로 정리하기   (난이도: 중하, 18점)
==================================================================
"액션" 장르 영화를 관객수가 많은 순서(흥행 순서)대로
정리하여 출력하려고 합니다. 표기는 "제목(관객수만명)" 형태입니다.

[처리해야 할 일]
 1. 장르가 "액션"인 영화만 골라낸다.
 2. 관객수가 많은 순서(내림차순)가 되도록 순서를 정렬한다.
 3. 각 영화를 "제목(관객수만명)" 형태의 문자열로 바꾼다.
    (예: 괴물(1301만명))
 4. 한 줄에 하나씩 출력한다.

[예상 출력 결과]
== 액션 장르 영화 (관객수 내림차순) ==
괴물(1301만명)
암살(1270만명)
부산행(1156만명)


==================================================================
 3번. 장르별 영화 편수 집계 후 정렬   (난이도: 중, 20점)
==================================================================
장르별로 영화가 몇 편씩 있는지 세어 정리하려고 합니다.

[처리해야 할 일]
 1. 같은 장르끼리 묶어, 장르별 영화 "편수"를 센다.
 2. 집계 결과를 아래 두 기준으로 정렬한다.
      - 1차 기준: 편수가 많은 순서(내림차순)
      - 2차 기준: 편수가 같으면 장르명 가나다순(오름차순)
 3. "장르 : N편" 형태로 한 줄씩 출력한다.

[안내]
 - 장르별로 묶어 집계한 결과는 순서가 보장되지 않습니다.
   따라서 출력 전에 위 기준대로 다시 정렬하는 과정이 필요합니다.
 - 드라마와 액션은 각각 3편으로 편수가 같으므로,
   장르명 가나다순(드라마 -> 액션)으로 출력됩니다.

[예상 출력 결과]
== 장르별 영화 편수 (편수 내림차순, 동률은 장르명 가나다순) ==
드라마 : 3편
액션 : 3편
스릴러 : 2편


==================================================================
 4번. 최근 영화 관객수 통계 + 최다 흥행작   (난이도: 중상, 22점)
==================================================================
"2015년 이후(2015년 포함)" 개봉한 영화들의 관객수 통계를 내고,
그 중 관객수가 가장 많은 영화를 찾으려고 합니다.

[처리해야 할 일]
 1. 개봉연도(year)가 2015년 이상인 영화만 골라낸다.
 2. 골라낸 영화들의 관객수에 대한 통계(편수, 합계, 최대, 최소, 평균)를
    한 번에 구한다.
 3. 아래 형식으로 통계를 출력한다. (평균은 소수점 첫째 자리까지)
      편수 : N편
      합계 : N만명
      최대 : N만명
      최소 : N만명
      평균 : N.N만명
 4. 마지막으로, 2015년 이후 영화 중 관객수가 가장 많은 영화의
    제목을 출력한다.

[안내]
 - 여러 통계 값(개수/합/최대/최소/평균)을 한 번에 얻어내는
   "요약 통계" 기능을 활용하면 편리합니다.
 - 평균은 소수점 첫째 자리까지 표기합니다. (예: 951.0)
 - 2015년 이후 영화는 부산행, 암살, 택시운전사, 곡성, 기생충,
   82년생김지영 으로 총 6편입니다.

[예상 출력 결과]
== 2015년 이후 개봉 영화 관객수 통계 ==
편수 : 6편
합계 : 5706만명
최대 : 1270만명
최소 : 367만명
평균 : 951.0만명
최다 관객 영화 : 암살


==================================================================
 5번. 종합 - 호평 영화의 장르별 총 관객수   (난이도: 상, 25점)
==================================================================
"평점 85점 이상"의 호평 영화만 대상으로, 장르별 총 관객수를 구해
흥행 보고서를 한 줄로 만들려고 합니다.

[처리해야 할 일]
 1. 평점(score)이 85점 이상인 영화만 골라낸다.
 2. 골라낸 영화를 장르별로 묶어, 장르별 "관객수(audience)의 합계"를 구한다.
 3. 총 관객수가 큰 순서(내림차순)로 정렬한다.
 4. 각 항목을 "장르(총관객수만명)" 형태로 바꾸고,
    전체를 " > " 로 이어 한 줄로 출력한다.
    (예: 액션(2457만명) > 드라마(2226만명) > ...)
 5. 마지막 줄에 총 관객수가 가장 많은 장르의 이름을 출력한다.

[안내]
 - 평점 85점 이상 영화는 기생충(95), 괴물(88), 올드보이(92),
   부산행(85), 택시운전사(89), 곡성(87) 입니다.
   (암살 83, 82년생김지영 80 은 제외됩니다.)
 - 액션 = 괴물(1301) + 부산행(1156) = 2457만명 처럼 합산됩니다.
 - 장르별로 묶어 합계를 구한 결과는 순서가 보장되지 않으므로,
   출력 전에 합계 기준으로 다시 정렬해야 합니다.

[예상 출력 결과]
== 평점 85점 이상, 장르별 총 관객수 (내림차순) ==
액션(2457만명) > 드라마(2226만명) > 스릴러(1013만명)
최다 관객 장르: 액션
