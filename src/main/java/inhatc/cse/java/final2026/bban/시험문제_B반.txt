##################################################################
# 1세트. 동물원 동물
##################################################################
각 동물(Animal)은 이름(name), 분류(type), 나이(age), 몸무게(weight) 정보를 가집니다.

[데이터]
("사자",   "포유류",  8,  190)
("코끼리", "포유류", 15, 5000)
("펭귄",   "조류",    5,   30)
("독수리", "조류",   10,    6)
("거북이", "파충류", 30,  120)
("악어",   "파충류", 12,  200)
("기린",   "포유류",  7,  800)

------------------------------------------------------------------
 1번. 조건을 만족하는 동물 수 세기  
------------------------------------------------------------------
 1. 나이가 10살 이상이면서 20살 이하인 동물만 골라낸다.
 2. 골라낸 동물이 몇 마리인지 센 뒤 "N마리" 형태로 출력한다.

[예상 출력 결과]
== 나이 10살 이상 20살 이하 동물 수 ==
N마리

------------------------------------------------------------------
 2번. 몸무게 상위 3마리 뽑기
------------------------------------------------------------------
 1. 전체 동물을 몸무게가 무거운 순서(내림차순)로 정렬한다.
 2. 그 중 상위 3마리만 남긴다.
 3. "이름(몸무게kg)" 형태로 바꿔 한 줄에 하나씩 출력한다.

[예상 출력 결과]
== 몸무게 상위 3마리 ==
동물1(000kg)
동물2(000kg)
...

------------------------------------------------------------------
 3번. 세 가지 조건 판정하기  
------------------------------------------------------------------
다음 두 가지를 각각 판정하여 "예" 또는 "아니오" 로 출력한다.
 1. 모든 동물의 몸무게가 100kg 이상인가? (전체가 만족하는지)
 2. 나이가 25살 이상인 동물이 하나라도 있는가? (하나라도 만족하는지)
 
[예상 출력 결과]
== 조건 판정 ==
모든 동물의 몸무게가 100kg 이상인가? (예/아니오)
나이 25살 이상 동물이 있는가? (예/아니오)

------------------------------------------------------------------
 4번. 몸무게 극값 동물 찾기  
------------------------------------------------------------------
 1. 몸무게가 가장 무거운 동물의 이름을 구한다.
 2. 몸무게가 가장 가벼운 동물의 이름을 구한다.

[예상 출력 결과]
== 몸무게 극값 동물 ==
가장 무거운 동물: 동물1
가장 가벼운 동물: 동물2

##################################################################
# 2세트. 식당 메뉴
##################################################################
각 메뉴(Menu)는 메뉴명(name), 분류(category), 가격(price), 칼로리(calorie) 정보를 가집니다.

[데이터]
("비빔밥",   "한식",  9000,  600)
("김치찌개", "한식",  8000,  450)
("짜장면",   "중식",  7000,  800)
("탕수육",   "중식", 15000, 1200)
("초밥",     "일식", 13000,  500)
("우동",     "일식",  8500,  550)
("돈까스",   "일식", 10000,  950)

------------------------------------------------------------------
 1번. 전체 가격 합계 구하기  
------------------------------------------------------------------
 1. 전체 메뉴의 가격(price)을 모두 더한다.
 2. 합계를 "N원" 형태로 출력한다.

[예상 출력 결과]
== 전체 메뉴 가격 합계 ==
000원

------------------------------------------------------------------
 2번. 분류별 메뉴 개수 세기  
------------------------------------------------------------------
 1. 같은 분류끼리 묶어 분류별 "메뉴 개수"를 센다.
 2. 분류명 가나다순으로 정렬한다.
 3. "분류 : N개" 형태로 한 줄씩 출력한다.

[예상 출력 결과]
== 분류별 메뉴 개수 (분류명 가나다순) ==
분류1 : N개
분류2 : N개
...

------------------------------------------------------------------
 3번. 가격 기준으로 두 그룹으로 나누기  
------------------------------------------------------------------
 1. 전체 메뉴를 가격 10,000원 기준으로 "이상" 그룹과 "미만" 그룹
    두 묶음으로 한 번에 나눈다. (참/거짓 분할)
 2. [10,000원 이상] 그룹의 이름을, 이어서 [10,000원 미만] 그룹의 이름을 출력한다.
 3. 각 이름 앞에는 공백 2칸을 붙인다. 그룹 내 순서는 원본 순서를 따른다.

[예상 출력 결과]
== 가격 10,000원 기준 분할 ==
[10,000원 이상]
  메뉴1
  메뉴2
  ...
[10,000원 미만]
  메뉴1
  메뉴2
  ...

------------------------------------------------------------------
 4번. 종합 - 인기 메뉴의 분류별 가격 합계  
------------------------------------------------------------------
 1. 가격(price)이 8,000원 이상인 메뉴만 골라낸다.
 2. 분류별로 묶어 분류별 "가격 합계"를 구한다.
 3. 합계가 큰 순서(내림차순)로 정렬한다.
 4. "분류 : N원" 형태로 한 줄씩 출력한다.
 5. 마지막 줄에 가격 합계가 가장 큰 분류명을 "가격 합계 1위 분류: 분류" 형태로 출력한다.

[예상 출력 결과]
== 가격 8,000원 이상, 분류별 가격 합계 (내림차순) ==
분류1 : 000원
분류2 : 000원
분류3 : 000원
가격 합계 1위 분류: 분류1
