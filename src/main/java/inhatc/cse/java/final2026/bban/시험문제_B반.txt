------------------------------------------------------------------
 공통 데이터 - 주문(Order) 리스트
------------------------------------------------------------------
각 주문은 고객(customer), 메뉴(menu), 카테고리(category),
단가(price), 수량(quantity) 정보를 가집니다.

static class Order {
    String customer;
    String menu;
    String category;
    int price;     // 단가(원)
    int quantity;  // 수량(개)

    public Order(String customer, String menu, String category, int price, int quantity) {
        this.customer = customer;
        this.menu = menu;
        this.category = category;
        this.price = price;
        this.quantity = quantity;
    }
    public String getCustomer() { return customer; }
    public String getMenu()     { return menu; }
    public String getCategory() { return category; }
    public int    getPrice()    { return price; }
    public int    getQuantity() { return quantity; }
}

List<Order> orders = Arrays.asList(
    new Order("김민준", "아메리카노", "커피",   4500, 2),
    new Order("이서연", "카페라떼",   "커피",   5000, 1),
    new Order("박도윤", "녹차라떼",   "티",     5500, 3),
    new Order("최지우", "치즈케이크", "디저트", 6500, 1),
    new Order("김민준", "아메리카노", "커피",   4500, 1),
    new Order("정시우", "얼그레이",   "티",     5000, 2),
    new Order("이서연", "티라미수",   "디저트", 7000, 2),
    new Order("박도윤", "에스프레소", "커피",   4000, 1)
);

* 결제금액 계산 규칙: 한 주문의 결제금액 = 단가 x 수량
  예) 아메리카노 4500원 x 2개 = 9000원

 1번. 비싼 메뉴 이름 목록 만들기 (중복 없이)   (난이도: 하, 15점)
==================================================================
메뉴판에서 "단가가 5,000원 이상"인 메뉴 이름을,
중복 없이 가나다순으로 정리한 목록을 출력하려고 합니다.

[처리해야 할 일]
 1. 전체 주문 중에서 단가(price)가 5,000원 이상인 주문만 골라낸다.
 2. 골라낸 주문에서 "메뉴 이름"이라는 값 하나만 뽑아낸다.
 3. 같은 메뉴가 여러 번 주문되었을 수 있으므로, 같은 이름은 한 번만 남긴다.
 4. 남은 메뉴 이름을 가나다순(오름차순)으로 나열하여 한 줄에 하나씩 출력한다.

[예상 출력 결과]
== 단가 5,000원 이상 메뉴 (중복제거, 가나다순) ==
녹차라떼
얼그레이
치즈케이크
카페라떼
티라미수


==================================================================
 2번. 특정 카테고리의 총 매출 계산하기   (난이도: 중하, 18점)
==================================================================
"커피" 카테고리에서 발생한 총 매출(결제금액의 합)을 계산하려고 합니다.

[처리해야 할 일]
 1. 카테고리가 "커피"인 주문만 골라낸다.
 2. 각 주문을 결제금액(단가 x 수량)이라는 숫자 값으로 바꾼다.
 3. 그 숫자들을 모두 더해 총 매출을 구하고 "N원" 형태로 출력한다.

[안내]
 - 각 주문을 숫자로 바꿀 때 "단가 x 수량" 계산식을 직접 넣어야 합니다.
 - 커피 주문은 아메리카노(4500x2), 카페라떼(5000x1),
   아메리카노(4500x1), 에스프레소(4000x1) 입니다.

[예상 출력 결과]
== 커피 카테고리 총 매출 ==
22500원


==================================================================
 3번. 고객별 주문 건수 집계 후 정렬   (난이도: 중, 20점)
==================================================================
고객들이 각각 몇 번 주문했는지 세어 정리하려고 합니다.
(결제 "금액"이 아니라 주문 "건수"를 세는 것에 주의하세요.)

[처리해야 할 일]
 1. 같은 고객끼리 묶어, 고객별 주문 "건수"를 센다.
 2. 집계 결과를 아래 두 기준으로 정렬한다.
      - 1차 기준: 건수가 많은 순서(내림차순)
      - 2차 기준: 건수가 같으면 고객명 가나다순(오름차순)
 3. "고객명 : N건" 형태로 한 줄씩 출력한다.

[안내]
 - 고객별로 묶어 집계한 결과는 순서가 보장되지 않습니다.
   따라서 출력 전에 위 기준대로 다시 정렬하는 과정이 필요합니다.
 - 김민준/박도윤/이서연은 모두 2건으로 같으므로,
   고객명 가나다순으로 출력됩니다.

[예상 출력 결과]
== 고객별 주문 건수 (건수 내림차순, 동률은 고객명 가나다순) ==
김민준 : 2건
박도윤 : 2건
이서연 : 2건
정시우 : 1건
최지우 : 1건


==================================================================
 4번. 고객별 총 결제금액 집계 + VIP 선정   (난이도: 중상, 22점)
==================================================================
이번에는 고객별 총 결제금액(단가 x 수량의 합)을 구하고,
가장 많이 결제한 VIP 고객을 찾으려고 합니다.

[처리해야 할 일]
 1. 같은 고객끼리 묶되, 각 주문의 결제금액(단가 x 수량)을 합산하여
    고객별 총 결제금액을 구한다.
 2. 금액이 큰 순서(내림차순)로 정렬하여 "고객명 : N원" 형태로 출력한다.
 3. 마지막 줄에 총 결제금액이 가장 큰 고객(VIP)의 이름을 출력한다.

[안내]
 - 한 고객의 주문이 여러 건이면, 각 건의 결제금액을 모두 더해야 합니다.
   박도윤 = 녹차라떼(5500x3=16500) + 에스프레소(4000x1=4000) = 20500원
   이서연 = 카페라떼(5000x1=5000) + 티라미수(7000x2=14000) = 19000원
 - 집계 결과는 순서가 보장되지 않으므로, 금액 기준으로 다시 정렬해야 합니다.

[예상 출력 결과]
== 고객별 총 결제금액 (내림차순) ==
박도윤 : 20500원
이서연 : 19000원
김민준 : 13500원
정시우 : 10000원
최지우 : 6500원
VIP 고객: 박도윤


==================================================================
 5번. 종합 - 다량 주문의 카테고리별 매출 상위 2개   (난이도: 상, 25점)
==================================================================
"한 번에 2개 이상" 주문된 건만 대상으로, 카테고리별 매출을 구하고
가장 매출이 큰 상위 2개 카테고리를 한 줄로 보고하려고 합니다.

[처리해야 할 일]
 1. 전체 주문 중에서 수량(quantity)이 2개 이상인 주문만 골라낸다.
 2. 골라낸 주문을 카테고리별로 묶되, 각 건의 결제금액(단가 x 수량)을
    합산하여 카테고리별 총 매출을 구한다.
 3. 매출이 큰 순서(내림차순)로 정렬한다.
 4. 그 중 상위 2개 카테고리만 남긴다.
 5. 각 항목을 "카테고리:금액원" 형태로 바꾸고,
    전체를 " | " 로 이어 한 줄로 출력한다.

[안내]
 - 수량 2개 이상인 주문은
   아메리카노(커피, 4500x2=9000), 녹차라떼(티, 5500x3=16500),
   얼그레이(티, 5000x2=10000), 티라미수(디저트, 7000x2=14000) 입니다.
 - 따라서 카테고리별 합계는 커피 9000, 티 26500, 디저트 14000 이 되고,
   상위 2개는 티와 디저트입니다.

[예상 출력 결과]
== 수량 2개 이상 주문, 카테고리별 매출 상위 2개 ==
티:26500원 | 디저트:14000원

 5번 (25점) : 조건 걸러내기 + 그룹별 합계 + 정렬 + 상위 N개 + 한 줄 연결
