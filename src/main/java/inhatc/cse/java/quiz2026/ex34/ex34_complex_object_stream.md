# 2026년도 34번 - Stream 객체 리스트 복잡 처리

학생 리스트에서 점수 80점 이상인 학생만 선택하여 이름으로 정렬한 후, 상위 3명의 이름을 출력하세요.

## 데이터
```java
new Student(1001, "Kim", 85)
new Student(1002, "Lee", 75)
new Student(1003, "Park", 90)
new Student(1004, "Choi", 88)
new Student(1005, "Jung", 92)
new Student(1006, "Kang", 70)
```

## 요구사항
- `filter()`로 80점 이상 선택
- `sorted()`로 이름 기준 정렬
- `limit(3)`으로 상위 3명
- 결과 출력
