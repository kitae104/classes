# quiz2026 사용 메소드 목록

> `inhatc.cse.java.quiz2026` (ex05 ~ ex50) 전체 소스에서 호출된 메소드를

## Stream API 사용 메소드 (중복 제거)

### 1. 스트림 생성 / 소스
- `stream()`
- `parallel()`  *(병렬 스트림, ex48)*
- `IntStream.range()` · `IntStream.rangeClosed()` · `IntStream.of()`  *(ex41 등)*
- `Arrays.asList()` · `List.of()`

### 2. 중간 연산 (Intermediate)
- `filter()`
- `map()` · `mapToInt()` · `mapToLong()`
- `flatMap()`
- `sorted()`
- `distinct()`
- `limit()` · `skip()`
- `peek()`

### 3. 최종 연산 (Terminal)
- `forEach()`
- `collect()` · `toList()`  *(Stream.toList())*
- `count()`
- `sum()` · `min()` · `max()` · `reduce()`
- `summaryStatistics()`
- `anyMatch()` · `allMatch()` · `noneMatch()`
- `findFirst()`

### 4. Collectors
- `toList()`
- `groupingBy()`
- `counting()`
- `summingInt()`
- `partitioningBy()`
- `joining()`
- `toMap()`
- `collectingAndThen()`

### 5. Comparator
- `comparing()` · `comparingInt()`
- `reversed()` · `thenComparing()`
- `reverseOrder()`

### 6. Optional / OptionalInt
- `get()` · `orElse()` · `isPresent()` · `ifPresent()`

### 7. IntSummaryStatistics
- `getCount()` · `getSum()` · `getMin()` · `getMax()` · `getAverage()`

### 8. Map / Map.Entry
- `entrySet()` · `getKey()` · `getValue()`
