# 2026년도 39번 - Stream 조건부 groupingBy

학생 리스트를 성별로 분류한 후, 각 그룹에서 점수 기준 내림차순으로 정렬하세요.

## 데이터
```java
new Student(1001, "Kim", "F", 85)
new Student(1002, "Lee", "M", 75)
new Student(1003, "Park", "M", 90)
new Student(1004, "Choi", "F", 88)
```

## 요구사항
- `groupingBy()`로 성별 분류
- 각 그룹 내에서 점수 내림차순 정렬
- 결과 출력
