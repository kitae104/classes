# 2026년도 45번 - Stream 정렬 (여러 기준)

학생(Student) 리스트를 점수 내림차순, 동점이면 이름 오름차순으로 정렬하세요.

## 데이터
```java
new Student("Kim", 90)
new Student("Lee", 85)
new Student("Park", 90)
new Student("Choi", 85)
```

## 요구사항
- `Comparator.comparing().reversed()` 와 `thenComparing()` 사용
- 점수 내림차순, 동점 이름 오름차순
- 결과 출력
