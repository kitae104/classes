# 2026년도 27번 - Stream with custom class (Student)

학생 객체 리스트에서 점수 70점 이상인 학생만 필터링하여 이름을 출력하세요.

## 데이터
```java
new Student(1001, "Kim", 85)
new Student(1002, "Lee", 65)
new Student(1003, "Park", 90)
new Student(1004, "Choi", 75)
```

## 요구사항
- `filter()`로 점수 70점 이상인 학생 선택
- `map()`으로 이름 추출
- 결과 출력
