# 2026년도 50번 - Stream 종합 실습 (회원 관리)

회원(Member) 리스트에서:
1. 나이 18세 이상만 필터링
2. 각 회원을 "이름(나이)" 형식의 문자열로 변환
3. 이름 오름차순 정렬
4. 최대 5명 선택
5. 쉼표로 구분한 문자열로 변환

## 데이터
```java
new Member("Kim", 25), new Member("Lee", 17), new Member("Park", 30), 
new Member("Choi", 20), new Member("Jung", 16), new Member("Kang", 28)
```

## 요구사항
- `filter()`, `map()`, `sorted()`, `limit()`, `joining()` 모두 사용
- 최종 결과는 문자열로 출력
